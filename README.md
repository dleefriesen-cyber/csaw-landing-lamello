# csaw-landing-lamello

Lamello Meta Ads landing page (VSL + Buy Now / Find a Dealer).

Edit the `window.LP` settings block at the top of `index.html`:
- `youtubeId` / `vimeoId` / `mp4Url` — the VSL video
- `cartUrl` — default Buy Now link
- `affiliates` — per-creator cart links, selected by `?a=<code>` in the ad URL
- `metaPixelId` — Meta Pixel ID
